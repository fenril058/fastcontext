# Code of Conduct

This project has adopted the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: participate respectfully, assume good faith, and accept that a volunteer maintainer may
decline your change without owing you a debate.

## Enforcement

This repository is no longer covered by the Microsoft Open Source Code of Conduct, and
`opencode@microsoft.com` will not act on reports about it.

Report unacceptable behaviour to the maintainer privately using GitHub's
[report abuse](https://github.com/contact/report-abuse) form, or by opening a
[private security advisory](https://github.com/fenril058/fastcontext/security/advisories/new) if you
would rather the report stay off the public tracker. Reports will be reviewed as time allows and kept
confidential.
