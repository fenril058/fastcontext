# Code of Conduct

This project has adopted the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, unmodified. The linked text is the authoritative version; nothing here overrides it.

## Enforcement

This repository is no longer covered by the Microsoft Open Source Code of Conduct, and
`opencode@microsoft.com` will not act on reports about it.

**There is currently no private reporting channel that reaches the maintainer.** Being straight about
that is better than naming one that does not work:

- Opening an [issue](https://github.com/fenril058/fastcontext/issues) reaches the maintainer, but it
  is public.
- GitHub's [report abuse](https://github.com/contact/report-abuse) form is private, but it goes to
  GitHub Support, not to this repository's maintainer, and is appropriate only for conduct that
  violates GitHub's own terms.

Reports are handled by a single volunteer as time allows. If you need a private channel, say so in an
issue without details and one will be arranged.
